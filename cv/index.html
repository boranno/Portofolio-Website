Selected Engineering Projects

PROJECT 01 July 2025 – September 2026 Embedded AI · IoT · Final-Year Design Project

IoT Based Poultry Farm Environmental Monitoring System

Individual final-year design project completed at Daffodil International University under the supervision of Mr. Md. Sadekur Rahman (Grade: A, 3.75).

  • Built an ESP32-S3 hardware prototype with DHT22 temperature and humidity sensors and an MQ-135 ammonia sensor.
  • Tested on a real poultry farm in Bangladesh, collecting 5,000 real sensor readings (4,920 retained after de-duplication).
  • Compared seven machine learning models and deployed an INT8-quantised neural network of 4.4 KB using TensorFlow Lite Micro.
  • Developed a web dashboard using Chart.js and Firebase Realtime Database with email alerts.
GitHub Repository Portfolio Case Study
PROJECT 02 Academic Research · Machine Learning

Predicting the Impact of Procrastination on Academic Performance

Machine learning research study examining the relationship between student procrastination habits and academic performance using primary survey data.

  • Designed and conducted a survey on procrastination habits and academic performance, and published the dataset on Kaggle.
  • Cleaned and encoded collected survey responses, applied SMOTE for class balancing, and used chi-squared feature selection.
  • Compared eight classifiers: Logistic Regression, Decision Tree, KNN, Naive Bayes, Random Forest, Gradient Boosting, CatBoost, and XGBoost, alongside a voting ensemble.
  • Applied SHAP-based explanations to interpret model predictions.
GitHub Repository Portfolio Case Study
PROJECT 03 May 2024 Computer Vision · Python

Campus Guardian: Face-Recognition Security System

Python-based face-recognition security prototype built with OpenCV and the face_recognition library for monitored access workflows.

  • Built a Python face-recognition security system using OpenCV and the face_recognition library.
  • Implemented multi-camera monitoring and role-based access control.
  • Implemented entry and exit logging alongside intruder detection.
PROJECT 04 NASA Space Apps Challenge 2026 Team: Daydreammer · Decision Support
